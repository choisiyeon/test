## 3. 시나리오 상세 (Given-When-Then)

### AC-04-01 최근 접수 순 기본 정렬  `정상` `E2E`

```gherkin
Scenario: 최근 접수 순 기본 정렬
  Given 직원으로 로그인되어 있다
  When 접수 목록을 연다
  Then 가장 최근에 접수된 건이 첫 번째 행에 표시된다
```

### AC-04-02 조건별 검색  `정상` `통합`

```gherkin
Scenario: 조건별 검색
  Given 접수 여러 건이 등록되어 있다
  When 상태 "작업중"으로 검색한다
  Then 상태가 "작업중"인 건만 표시된다
  When 검색어 "김철"을 입력한다
  Then 고객명에 "김철"이 포함된 건만 표시된다
  When 검색어 "5678"을 입력한다
  Then 전화번호 끝 4자리가 5678인 고객의 건만 표시된다
  When 검색어로 접수번호 "20261120-003"을 입력한다
  Then 해당 접수 1건만 표시된다
```

### AC-04-03 기한 경과만 보기  `정상` `통합`

```gherkin
Scenario: 기한 경과만 보기
  Given 접수 P, Q, R이 있다
  When [기한 경과만]을 선택한다
  Then 접수 P만 표시된다
    And 완료된 접수 Q와 예정일이 남은 접수 R은 표시되지 않는다
```

### AC-04-04 기한 경과 강조 표시  `정상` `E2E`

```gherkin
Scenario: 기한 경과 강조 표시
  Given 접수 P가 기한 경과 상태다
  When 접수 목록을 연다
  Then 접수 P의 완료 예정일에 ⚠ 표시와 붉은 글씨가 적용된다
```

### AC-04-05 검색 결과 없음 안내  `예외` `E2E`

```gherkin
Scenario: 검색 결과 없음 안내
  Given 고객명 "없는사람"인 접수가 없다
  When "없는사람"으로 검색한다
  Then "검색 결과가 없습니다"가 표시된다
```

### AC-04-06 목록 개인정보 가림  `보안` `단위·통합`

```gherkin
Scenario: 목록 개인정보 가림
  Given 고객 "김철수"(01098765678)의 접수가 있다
  When 접수 목록을 조회한다
  Then 고객명이 "김*수", 전화번호가 "010-****-5678"로 표시된다
    And API 응답에 이름·전화번호 원문이 포함되지 않는다
```

### AC-04-07 검색 조건 유지  `정상` `E2E`

```gherkin
Scenario: 검색 조건 유지
  Given 상태 "작업중"으로 검색한 목록을 보고 있다
  When 접수 상세로 이동했다가 뒤로가기를 누른다
  Then 검색 조건과 결과가 그대로 유지된다
```
