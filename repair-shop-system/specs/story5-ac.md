## 3. 시나리오 상세 (Given-When-Then)

### AC-05-01 고객 등록  `정상` `E2E`

```gherkin
Scenario: 고객 등록
  Given 직원으로 로그인되어 고객 관리 화면을 열었다
  When 이름 "이영수", 전화번호 "010-4444-5555", 메모 "단추 여분 보관"을 입력하고 저장한다
  Then 고객 목록에 "이*수"가 표시된다
```

### AC-05-02 같은 번호 고객 안내 후 선택  `예외` `통합·E2E`

```gherkin
Scenario: 같은 번호 고객 안내 후 선택
  Given 전화번호 01012345678 고객 "홍길동"이 있다
  When 같은 번호로 "홍길순"을 등록한다
  Then "같은 번호의 고객이 있습니다" 안내와 기존 고객 목록이 표시된다
  When [그래도 등록]을 누른다
  Then "홍길순"이 새 고객으로 등록된다
  When 다시 같은 번호로 등록하고 [기존 고객 선택]을 누른다
  Then 새 고객이 만들어지지 않고 기존 고객이 선택된다
```

### AC-05-03 전화번호 형식 오류 거부  `입력 검증` `단위·통합`

```gherkin
Scenario: 전화번호 형식 오류 거부
  Given 직원이 고객 등록 화면을 열었다
  When 전화번호에 "0101234"를 입력해 저장한다
  Then 저장되지 않고 전화번호 형식 안내가 표시된다
```

### AC-05-04 전화번호 숫자만 저장  `정상` `단위`

```gherkin
Scenario: 전화번호 숫자만 저장
  Given 고객 등록 화면이다
  When 전화번호를 "010-4444-5555" 또는 "01044445555"로 입력해 저장한다
  Then 두 경우 모두 "01044445555"로 저장된다
```

### AC-05-05 고객 정보 수정과 변경 이력  `정상` `통합·E2E`

```gherkin
Scenario: 고객 정보 수정과 변경 이력
  Given 고객 "홍길동" 상세 화면이다
  When [수정]을 눌러 메모를 "허리 치수 32"로 바꾸고 저장한다
  Then 변경된 메모가 표시된다
    And 변경 이력에 항목(메모), 변경 전·후 값, 변경자, 일시가 기록된다
```

### AC-05-06 변경 이력의 전화번호 가림  `보안` `통합`

```gherkin
Scenario: 변경 이력의 전화번호 가림
  Given 고객 전화번호를 수정했다
  When 변경 이력을 확인한다
  Then 변경 전·후 전화번호가 가림 처리된 형태로만 저장되어 있다
```

### AC-05-07 접수 화면 신규 고객 팝업 동일 동작  `정상` `E2E`

```gherkin
Scenario: 접수 화면 신규 고객 팝업 동일 동작
  Given 수선 접수 화면에서 [+신규]를 눌렀다
  When 이미 있는 번호를 입력해 저장한다
  Then 고객 관리 화면과 같은 중복 안내가 표시된다
```
