## 3. 시나리오 상세 (Given-When-Then)

### AC-08-01 기준 일수 경과 건만 표시  `정상` `통합`

```gherkin
Scenario: 기준 일수 경과 건만 표시
  Given 미수령 기준 일수가 N일로 설정되어 있다
  When 미수령 목록을 연다
  Then 완료 후 N일을 넘긴 '완료' 상태 건만 표시된다
    And 출고된 건과 기준 일수가 지나지 않은 건은 표시되지 않는다
    And 경과 일수가 긴 순으로 정렬된다
```

### AC-08-02 기준 일수 경계값  `정상` `단위·통합`

```gherkin
Scenario: 기준 일수 경계값
  Given 미수령 기준 일수가 N일이다
  When 완료 후 정확히 N일이 지난 건과 N+1일이 지난 건을 확인한다
  Then 기준(초과 / 이상) 확정안에 따라 포함 여부가 일관되게 판단된다
```

### AC-08-03 표시 항목  `정상` `E2E`

```gherkin
Scenario: 표시 항목
  Given 미수령 건이 있다
  When 미수령 목록을 연다
  Then 접수번호, 고객명(가림), 품목, 완료일, 경과 일수, 알림 발송 횟수, 마지막 발송일이 표시된다
```

### AC-08-04 기준 일수 변경 시 재계산  `정상` `통합`

```gherkin
Scenario: 기준 일수 변경 시 재계산
  Given 관리자로 로그인되어 있다
  When 미수령 기준 일수를 더 작은 값으로 바꾼다
  Then 미수령 목록 건수가 새 기준에 맞게 늘어난다
```

### AC-08-05 대시보드 연결  `정상` `E2E`

```gherkin
Scenario: 대시보드 연결
  Given 미수령 건이 있다
  When 대시보드의 미수령 카드를 누른다
  Then 미수령 목록으로 이동하고 카드 숫자와 목록 건수가 같다
```

### AC-08-06 기준 미설정 안내  `예외` `E2E`

```gherkin
Scenario: 기준 미설정 안내
  Given 미수령 기준 일수가 설정되지 않았다
  When 미수령 목록을 연다
  Then "설정에서 미수령 기준 일수를 지정하세요"가 표시된다
```

### AC-08-07 직원 기준 변경 차단  `권한` `통합`

```gherkin
Scenario: 직원 기준 변경 차단
  Given 직원으로 로그인되어 있다
  When 미수령 기준 일수 변경 API를 요청한다
  Then 403 응답이 반환된다
```

### AC-08-08 기준값 입력 검증  `입력 검증` `통합`

```gherkin
Scenario: 기준값 입력 검증
  Given 관리자로 로그인되어 있다
  When 기준 일수를 0 또는 문자로 저장한다
  Then 저장되지 않고 "1 이상의 숫자를 입력하세요" 안내가 표시된다
```
