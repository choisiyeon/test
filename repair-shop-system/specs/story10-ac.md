## 3. 시나리오 상세 (Given-When-Then)

### AC-10-01 최근 발송 순 목록  `정상` `E2E`

```gherkin
Scenario: 최근 발송 순 목록
  Given 직원으로 로그인되어 있다
  When 알림 이력 화면을 연다
  Then 최근 발송 건이 첫 행에 표시된다
    And 발송 일시, 접수번호, 수신 번호(가림), 유형, 수단, 결과가 표시된다
```

### AC-10-02 조건 검색  `정상` `통합`

```gherkin
Scenario: 조건 검색
  Given 알림 이력이 여러 건 있다
  When 결과 "실패"로 검색한다
  Then 실패 건만 표시된다
  When 유형 "재안내"로 검색한다
  Then 재안내 건만 표시된다
  When 접수번호로 검색한다
  Then 해당 접수의 이력만 표시된다
```

### AC-10-03 실패 건 강조와 사유  `정상` `E2E`

```gherkin
Scenario: 실패 건 강조와 사유
  Given 실패 이력이 있다
  When 알림 이력 화면을 연다
  Then 실패 행이 붉은색으로 표시되고 실패 사유가 함께 표시된다
```

### AC-10-04 실패 건 재발송 시 이력 추가  `정상` `통합·E2E`

```gherkin
Scenario: 실패 건 재발송 시 이력 추가
  Given 완료 상태 접수의 실패 이력이 1건 있다
  When [다시 보내기]를 누른다
  Then 새 이력이 추가된다
    And 기존 실패 이력은 그대로 남는다
```

### AC-10-05 재발송 불가 건 비활성화  `예외` `E2E`

```gherkin
Scenario: 재발송 불가 건 비활성화
  Given 실패 이력이 있으나 해당 접수가 이미 "출고"되었다
  When 알림 이력 화면을 연다
  Then 해당 행의 [다시 보내기] 버튼이 비활성화되어 있다
```

### AC-10-06 접수 상세 내 이력  `정상` `E2E`

```gherkin
Scenario: 접수 상세 내 이력
  Given 접수 A에 이력 2건, 접수 B에 이력 1건이 있다
  When 접수 A 상세를 연다
  Then 접수 A의 이력 2건만 표시된다
```

### AC-10-07 문구 펼쳐 보기  `정상` `E2E`

```gherkin
Scenario: 문구 펼쳐 보기
  Given 알림 이력 화면이다
  When 이력 행을 누른다
  Then 발송 문구 전문이 펼쳐진다
```

### AC-10-08 이력 수정·삭제 불가  `보안` `통합`

```gherkin
Scenario: 이력 수정·삭제 불가
  Given 알림 이력이 있다
  When 이력 수정 또는 삭제 API를 요청한다
  Then 해당 기능이 제공되지 않는다(404 또는 405 응답)
```
