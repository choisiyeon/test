# [US-19] 수선 품목·기본 단가 설정 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E0 공통·설정 |
| 스토리 | 사장님으로서 수선 품목과 기본 단가를 등록하고 수정하고 싶다. 직원이 접수할 때 품목을 고르면 금액이 자동으로 입력되어 금액 착오를 줄이기 위해서다. |

| 작성일 | 2026-11-25 |

---

## 1. 요약

- 품목(예: 바지 기장, 허리 줄임, 지퍼 교체) 등록·수정·사용 중지·순서 변경
- 기본 단가는 선택 항목(품목에 따라 금액이 매번 다르면 비워 둠)
- 품목을 수정해도 이미 접수된 건의 품목명·금액은 바뀌지 않음(US-01에서 접수 시점 값 저장)
- 품목은 삭제하지 않고 '사용 중지' → 접수 화면 목록에서만 숨김, 매출 품목별 집계는 유지

---

## 2. 인수 조건

1. 관리자가 품목명과 기본 단가를 입력해 저장하면 접수 화면 품목 목록에 표시된다.
2. 기본 단가가 있는 품목을 접수 화면에서 고르면 금액 칸에 기본 단가가 입력된다(직원이 수정 가능).
3. 같은 이름의 품목은 등록할 수 없다.
4. 품목을 '사용 중지'하면 접수 화면 목록에서 사라지지만, 과거 접수와 매출 품목별 집계에는 그대로 남는다.
5. 품목 순서를 바꾸면 접수 화면 목록 순서에 반영된다.
6. 단가를 바꿔도 이미 접수된 건의 금액은 바뀌지 않는다.
7. 직원은 품목 설정 화면에 접근할 수 없다.

---

## 3. 데이터 모델 변경

```prisma
model ItemType {
  // ...US-01 항목(name @unique, basePrice?, sortOrder, active)
  category   String?            // 선택: 분류(상의·하의·기타 등), 사용 여부 확인 필요
  updatedAt  DateTime @updatedAt
}
```

- 단가 변경 이력이 필요하면 AuditLog(`ITEM_PRICE_CHANGE`, 이전·이후 단가)로 기록
- 초기 품목·단가는 매장 단가표를 받아 seed 또는 화면 입력(임의 값으로 채우지 않음)

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/item-types?includeInactive=` | 품목 목록(접수 화면: 사용 중만 / 설정 화면: 전체) | 사용 중: 전원 / 전체: 관리자 |
| POST | `/api/item-types` | 품목 등록 | 관리자 |
| PATCH | `/api/item-types/:id` | 이름·단가·분류·사용 여부 수정 | 관리자 |
| PUT | `/api/item-types/order` | 순서 일괄 변경(id 배열) | 관리자 |

```json
// POST 요청
{ "name": "바지 기장 줄임", "basePrice": null, "category": "하의" }
// 응답 409
{ "error": "DUPLICATE_NAME" }
```

### 검증 규칙

| 항목 | 규칙 |
| --- | --- |
| name | 필수, 1~30자, 앞뒤 공백 제거 후 중복 검사 |
| basePrice | 선택, 0 이상 정수(원) |

## 5. 화면 (S-08 설정 > 품목·단가)

```
수선 품목·기본 단가                      (단위: 원)        [+ 품목 추가]
│ ≡ │ 품목명        │ 분류 │ 기본 단가 │ 상태 │              │
│ ≡ │ 바지 기장 줄임 │ 하의 │ (미지정)  │ 사용 │ [수정][사용 중지] │
│ ≡ │ 지퍼 교체      │ 기타 │ (미지정)  │ 사용 │ [수정][사용 중지] │
※ ≡ 를 끌어 순서 변경 / 단가 변경은 이후 접수부터 적용
```

- 순서 변경은 끌어 놓기(drag and drop) + 접근성을 위한 [위로][아래로] 버튼 병행
- 접수 화면(S-03) 품목 선택에 분류별 묶음 표시(분류 사용 시)
