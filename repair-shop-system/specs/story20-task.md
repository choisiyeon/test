# [US-20] 알림 문구 설정 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E0 공통·설정 |
| 스토리 | 사장님으로서 고객에게 보내는 완료 안내·재안내 문구를 직접 고치고 싶다. 영업시간, 휴무일 등 매장 사정에 맞는 안내를 하기 위해서다. |
| 우선순위 / 릴리스 | 선택 / 2차 |
| 관련 화면 / 데이터 | S-08 설정(알림 문구 탭) / D-08 매장 설정 |
| 선행 작업 | US-09(문구 생성 함수), US-11(재안내) |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 완료 안내(DONE)·재안내(REMIND) 문구를 관리자가 수정, 변수(`#{매장명}`, `#{접수번호}` 등) 사용
- 저장 전 미리보기(예시 값으로 치환한 결과)와 글자 수 표시
- 문구 미설정 시 US-09 기본 문구 사용
- 매장명·매장 연락처 등 공통 정보도 이 화면에서 설정(StoreSetting)
- 카카오 알림톡은 승인된 템플릿만 발송 가능 → 알림톡 사용 시 '자유 수정'이 아니라 '승인 템플릿 선택 + 변수 값'만 설정하는 방식으로 동작(발송 업체 규정 확인 필요)

---

## 2. 인수 조건

1. 관리자가 완료 안내 문구를 수정해 저장하면 이후 발송되는 완료 안내에 새 문구가 사용된다.
2. 문구에 사용할 수 있는 변수 목록이 표시되고, 누르면 문구에 삽입된다.
3. 미리보기에 예시 값으로 치환된 문구와 글자 수가 표시된다.
4. 정의되지 않은 변수(예: `#{주소}`)가 있으면 저장되지 않고 안내가 표시된다.
5. [기본 문구로 되돌리기]를 누르면 기본 문구로 복원된다.
6. 매장명·매장 연락처를 저장하면 문구 변수와 접수증(US-01)에 반영된다.
7. 직원은 알림 문구 설정 화면에 접근할 수 없다.

---

## 3. 변수 정의

| 변수 | 값 | 예시 값(미리보기용) |
| --- | --- | --- |
| `#{매장명}` | StoreSetting `STORE_NAME` | ○○수선 |
| `#{매장연락처}` | StoreSetting `STORE_PHONE` | 02-000-0000 |
| `#{고객명}` | 고객 이름 | 홍길동 |
| `#{접수번호}` | 접수번호 | 20261125-007 |
| `#{품목}` | 접수 품목명 | 바지 기장 줄임 |
| `#{완료일}` | 완료 일자 | 11월 27일 |
| `#{경과일수}` | 완료 후 경과 일수(재안내 전용) | 20 |

※ 예시 값은 미리보기 표시용 가상 값

---

## 4. 데이터 모델

- StoreSetting 키 추가: `STORE_NAME`, `STORE_PHONE`, `NOTIFY_TEMPLATE_DONE`, `NOTIFY_TEMPLATE_REMIND`
- 알림톡 사용 시 추가 키: `ALIMTALK_TEMPLATE_CODE_DONE`, `ALIMTALK_TEMPLATE_CODE_REMIND`
- 문구 변경 이력: AuditLog(`NOTIFY_TEMPLATE_CHANGE`, 이전 문구 일부)

---

## 5. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/settings/notify-templates` | 문구·변수 목록·기본 문구 조회 | 관리자 |
| PUT | `/api/settings/notify-templates` | 문구 저장(변수 검증) | 관리자 |
| POST | `/api/settings/notify-templates/preview` | 미리보기(치환 결과·글자 수) | 관리자 |
| GET/PUT | `/api/settings/store-info` | 매장명·연락처 | 조회: 전원 / 변경: 관리자 |

```json
// PUT 요청
{ "type": "DONE", "text": "[#{매장명}] #{고객명}님, 맡기신 #{품목} 수선이 완료되었습니다. 접수번호 #{접수번호}" }
// 응답 422
{ "error": "UNKNOWN_VARIABLE", "variables": ["#{주소}"] }
```

### 처리 규칙

- 변수 검증: `/#\{([^}]+)\}/g`로 추출 → 정의 목록에 없으면 422
- 문구 길이 상한 설정(문자 단문 기준 초과 시 '장문 발송' 안내, 기준은 발송 업체 규정 확인 필요)
- US-09 `lib/notify/template.ts`가 설정값 → 없으면 기본 문구 순으로 사용하도록 수정
