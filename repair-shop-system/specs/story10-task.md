# [US-10] 알림 발송 이력 조회 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E3 완료 알림 |
| 스토리 | 직원으로서 고객에게 보낸 알림의 발송 일시와 결과를 확인하고 싶다. 고객이 "연락을 못 받았다"고 할 때 발송 여부를 확인하고 실패 건을 다시 보내기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 기능 | F-14 발송 이력 조회 |
| 관련 화면 / 데이터 | S-06 알림 이력, 접수 상세 / D-04 알림 이력 |
| 선행 작업 | US-09 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 전체 알림 이력 화면(기간·결과·유형·접수번호 검색)과 접수 상세 내 알림 이력 영역 구현
- 실패 건만 모아 보기 → 목록에서 바로 재발송(US-09 수동 재발송 API 사용)
- 이력은 조회 전용(수정·삭제 기능 없음)

---

## 2. 인수 조건

1. 알림 이력 화면을 열면 최근 발송 순으로 발송 일시, 접수번호, 수신 번호(가림), 유형, 수단, 결과가 표시된다.
2. 기간·결과(성공·실패·미설정)·유형(자동·수동·재안내)·접수번호로 검색할 수 있다.
3. 결과가 '실패'인 건은 붉은색으로 표시되고 실패 사유를 볼 수 있다.
4. 실패 건의 [다시 보내기]를 누르면 재발송되고 새 이력이 추가된다(기존 이력은 그대로 유지).
5. 접수 상세에서 해당 접수의 알림 이력만 볼 수 있다.
6. 발송 문구 전문은 행을 눌렀을 때만 펼쳐 보인다.

---

## 3. 데이터 모델

- 변경 없음(US-09 NotificationLog 사용)
- 접수 상태가 '완료'가 아니면(이미 출고 등) 재발송 버튼 비활성화

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/notifications?from=&to=&result=&type=&orderNo=&page=` | 전체 알림 이력 검색 | 관리자·직원 |
| GET | `/api/orders/:id/notifications` | 접수별 알림 이력(US-09에서 생성) | 관리자·직원 |

```json
{ "items": [
  { "id": "ck...", "createdAt": "2026-11-25T14:02:11+09:00", "orderId": "ck...", "orderNo": "20261125-007",
    "toMasked": "010-****-5678", "type": "DONE_AUTO", "channel": "ALIMTALK",
    "result": "FAILED", "failReason": "수신 번호 오류", "canResend": true } ],
  "page": 1, "total": 3 }
```

- 기간 기본값: 최근 7일(제안값)
- 기간 최대 범위 제한(예: 1년)으로 과도한 조회 방지(제안값)

---

## 5. 화면 (S-06 알림 이력)

```
[기간 11-19 ~ 11-25] [결과 전체▼] [유형 전체▼] [접수번호      ] [검색]   [실패만 보기]
│ 발송 일시       │ 접수번호      │ 수신 번호       │ 유형  │ 수단   │ 결과 │        │
│ 11-25 14:02    │ 20261125-007 │ 010-****-5678 │ 자동  │ 알림톡 │ 실패 │[다시보내기]│
│   └ 사유: 수신 번호 오류 / 문구: [펼치기]                                          │
```

- 접수 상세 하단 '알림 이력' 영역은 같은 표 컴포넌트를 접수 조건으로 재사용
- 대시보드(US-17)에 '오늘 발송 실패 n건' 표시 연결
