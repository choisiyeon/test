## 3. 시나리오 상세 (Given-When-Then)

### AC-15-01 조회 기간 그대로 내려받기  `정상` `E2E`

```gherkin
Scenario: 조회 기간 그대로 내려받기
  Given 관리자가 2026년 11월 일별 매출을 보고 있다
  When [엑셀 내려받기]를 누른다
  Then "매출_202611_일별_YYYYMMDD.xlsx" 파일이 내려받아진다
```

### AC-15-02 시트 구성  `정상` `통합`

```gherkin
Scenario: 시트 구성
  Given 내려받은 파일을 연다
  When 시트 목록을 확인한다
  Then "요약", "결제 상세", "품목별" 3개 시트가 있다
```

### AC-15-03 제목·단위·출처·기준일 표기  `정상` `통합`

```gherkin
Scenario: 제목·단위·출처·기준일 표기
  Given 내려받은 파일의 각 시트다
  When 상단과 하단을 확인한다
  Then 상단에 제목, 기간, "단위: 원"이 있다
    And 표 하단에 자료 출처와 기준일(내려받은 일시)이 있다
```

### AC-15-04 A4 인쇄 설정  `정상` `통합`

```gherkin
Scenario: A4 인쇄 설정
  Given 내려받은 파일이다
  When 인쇄 설정을 확인한다
  Then 용지 A4, 폭 1페이지 맞춤, 표 제목행 반복이 설정되어 있다
```

### AC-15-05 숫자 형식과 합계 수식  `정상` `통합`

```gherkin
Scenario: 숫자 형식과 합계 수식
  Given 요약 시트다
  When 금액 칸과 합계 행을 확인한다
  Then 금액은 천 단위 쉼표 숫자 형식이다
    And 합계 행은 SUM 수식으로 계산되어 있다
    And 파일 합계가 화면 합계와 같다
```

### AC-15-06 개인정보 미포함  `보안` `통합`

```gherkin
Scenario: 개인정보 미포함
  Given 결제 상세 시트다
  When 모든 셀을 확인한다
  Then 전화번호가 포함되어 있지 않다
    And 고객명은 가림 처리되어 있다
```

### AC-15-07 직원 차단  `권한` `통합`

```gherkin
Scenario: 직원 차단
  Given 직원으로 로그인되어 있다
  When 엑셀 내려받기 API를 요청한다
  Then 403 응답이 반환된다
```

### AC-15-08 내려받기 기록  `보안` `통합`

```gherkin
Scenario: 내려받기 기록
  Given 관리자가 파일을 내려받았다
  When 작업 기록을 확인한다
  Then 내려받기 기록(처리자, 일시, 기간)이 남아 있다
```
