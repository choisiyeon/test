# [US-14] 일·월 매출 조회 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E4 매출·정산 |
| 스토리 | 사장님으로서 일별·월별 매출을 결제수단별·품목별로 보고 싶다. 수작업 집계 없이 매출 현황을 파악하고 정산하기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 기능 | F-16 일·월 매출 집계 |
| 관련 화면 / 데이터 | S-07 매출·정산 / D-03 결제, D-02 접수 |
| 선행 작업 | US-12, US-13 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 매출 기준: 결제일(paidAt) 기준 결제 금액 합계, 취소는 취소일(canceledAt) 기준 차감
- 조회 단위: 일별(선택한 월의 날짜별), 월별(선택한 연도의 월별)
- 분류: 결제수단별(현금·카드·이체), 품목별
- 관리자 전용, 집계는 조회 시 SQL로 계산(매장 규모에서 별도 집계 테이블 불필요)

---

## 2. 인수 조건

1. 매출 화면에서 기간(일별: 월 선택, 월별: 연도 선택)을 고르면 기간별 결제 건수와 금액 합계가 표시된다.
2. 결제수단별 합계와 품목별 합계가 함께 표시된다.
3. 취소된 결제는 취소일에 차감 금액으로 표시되고 순매출에 반영된다.
4. 표 하단에 기간 전체 합계가 표시되며, 결제수단별 합계의 합과 전체 합계가 일치한다.
5. 직원은 매출 메뉴가 보이지 않고 API로 요청해도 거부된다.
6. 결제가 없는 날짜·월도 0원으로 표시된다.

---

## 3. 집계 규칙

| 항목 | 정의 |
| --- | --- |
| 총매출 | 기간 내 paidAt인 결제 금액 합(취소 여부 무관) |
| 취소액 | 기간 내 canceledAt인 결제 금액 합 |
| 순매출 | 총매출 − 취소액 |
| 기준 시간 | 한국 시간(KST) 0시~24시 |
| 미결제 출고 | 매출에 포함하지 않음, 별도 건수로 표시 |

```sql
-- 일별 순매출(예시)
WITH days AS (SELECT generate_series($1::date, $2::date, '1 day')::date AS d),
paid AS (SELECT (paid_at AT TIME ZONE 'Asia/Seoul')::date d, method, SUM(amount) amt, COUNT(*) cnt
         FROM payment WHERE paid_at >= $3 AND paid_at < $4 GROUP BY 1,2),
canc AS (SELECT (canceled_at AT TIME ZONE 'Asia/Seoul')::date d, method, SUM(amount) amt
         FROM payment WHERE canceled_at >= $3 AND canceled_at < $4 GROUP BY 1,2)
SELECT days.d, ... FROM days LEFT JOIN paid ... LEFT JOIN canc ...;
```

- Prisma `$queryRaw`로 실행, 집계 함수는 단위 테스트로 검증

| 메서드 | 경로 | 설명 | 권한 |

| GET | `/api/sales/daily?month=2026-11` | 일별 매출 | 관리자 |

## 5. 화면 (S-07 매출·정산)

```
매출·정산   [일별|월별]  [2026년 11월 ▼]                         (단위: 원)
│ 날짜  │ 건수 │ 현금 │ 카드 │ 이체 │ 취소 │ 순매출 │
│ 11-01 │      │      │      │      │      │        │
│ ...   │      │      │      │      │      │        │
│ 합계  │      │      │      │      │      │        │
품목별 합계: │ 품목 │ 건수 │ 금액 │
※ 결제일 기준, 취소는 취소일 기준 차감 / 미결제 출고 n건 별도
```

- 표 상단에 단위(원) 표기, 하단에 집계 기준과 조회 일시 표기
- 날짜 행 클릭 시 해당 날짜 결제 목록(접수번호·수단·금액) 펼침
- 엑셀 내려받기 버튼은 US-15에서 추가
