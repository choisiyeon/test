# [US-06] 고객 검색·수선 이력 조회 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E2 고객관리 |
| 스토리 | 직원으로서 고객을 이름이나 전화번호 뒷자리로 찾고 지난 수선 내역을 보고 싶다. 단골 고객의 이전 수선 내용과 금액을 바로 확인해 응대하기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 기능 | F-09 고객 검색, F-10 수선 이력 조회 |
| 관련 화면 / 데이터 | S-05 고객 관리 / D-01 고객, D-02 접수, D-03 결제 |
| 선행 작업 | US-01, US-05 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 고객 목록 검색(이름 부분 일치, 전화번호 뒤 4자리)과 고객 상세 화면(기본 정보 + 수선 이력) 구현
- 수선 이력은 최근 순, 건별 상태·금액·결제 여부 표시
- 접수 화면의 고객 검색(US-01)과 같은 검색 API 사용

---

## 2. 인수 조건

1. 이름 일부를 입력하면 해당 글자가 포함된 고객이 표시된다.
2. 숫자 4자리를 입력하면 전화번호 끝 4자리가 일치하는 고객이 표시된다.
3. 고객을 선택하면 상세 화면에 기본 정보, 총 접수 건수, 최근 방문일, 수선 이력이 표시된다.
4. 수선 이력의 각 건을 누르면 해당 접수 상세로 이동한다.
5. 고객 목록에서는 전화번호가 가려지고, 고객 상세에서는 전체 번호가 표시된다.
6. 고객 상세 화면에서 바로 [새 접수]를 누르면 해당 고객이 선택된 접수 화면이 열린다.

---

## 3. 데이터 모델

- 변경 없음. 이름 부분 검색 성능이 필요하면 PostgreSQL `pg_trgm` 인덱스 추가(고객 수가 많아질 경우 검토)
- 전화번호 끝 4자리 검색용 생성 컬럼 추가 제안: `phoneLast4 String` (저장 시 계산, 인덱스)

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/customers?q=&page=` | 고객 검색(US-01 API 확장: 페이지 처리, 요약 정보) | 관리자·직원 |
| GET | `/api/customers/:id` | 고객 상세(전체 번호 포함) | 관리자·직원 |
| GET | `/api/customers/:id/orders?page=` | 수선 이력 | 관리자·직원 |

```json
// GET /api/customers?q=5678
{ "items": [ { "id": "ck...", "name": "홍*동", "phoneMasked": "010-****-5678",
               "orderCount": 7, "lastOrderAt": "2026-11-20" } ], "total": 1 }

// GET /api/customers/:id/orders
{ "items": [ { "orderNo": "20261120-003", "itemTypeName": "셔츠", "description": "소매 수선",
               "amount": 12000, "status": "RELEASED", "paid": true, "createdAt": "2026-11-20" } ] }
```

- 검색 결과는 최근 방문일 순 정렬
- 고객 상세 조회 시 조회 기록(누가·언제)을 남길지 확인 필요(개인정보 열람 기록)

## 5. 화면 (S-05 고객 관리)

```
[이름 또는 전화번호 뒤 4자리      ] [검색]
┌──────┬───────────────┬──────┬──────────┐
│ 이름  │ 전화번호        │ 접수 수│ 최근 방문 │
│ 홍*동 │ 010-****-5678 │ 7     │ 11-20    │
└──────┴───────────────┴──────┴──────────┘

고객 상세 ─ 홍길동 / 010-1234-5678 / 메모: 단추 여분 보관   [수정] [새 접수]
수선 이력 (7건)
│ 20261120-003 │ 셔츠 │ 소매 수선 │ 12,000원 │ 출고 │ 결제완료 │
```

- 결제 여부는 US-12 구현 전까지 '-'로 표시
