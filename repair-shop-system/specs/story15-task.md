# [US-15] 매출 엑셀 내려받기 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E4 매출·정산 |
| 스토리 | 사장님으로서 매출 내역을 엑셀 파일로 내려받고 싶다. 세무 신고나 장부 정리에 그대로 활용하기 위해서다. |
| 우선순위 / 릴리스 | 선택 / 2차 |
| 관련 기능 | F-17 매출 엑셀 내려받기 |
| 관련 화면 / 데이터 | S-07 매출·정산 / D-03 결제 |
| 선행 작업 | US-14 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 매출 화면에서 조회 중인 기간 그대로 .xlsx 파일 생성(서버 생성, exceljs 라이브러리)
- 시트 구성: ① 요약(일별 또는 월별) ② 결제 상세(건별) ③ 품목별
- 엑셀 작성 원칙 반영: 단위 표기, 출처·기준일 기재, A4 인쇄 설정(용지 맞춤, 제목행 반복)
- 고객 개인정보는 파일에 넣지 않음(고객명 가림, 전화번호 제외)

---

## 2. 인수 조건

1. 매출 화면에서 [엑셀 내려받기]를 누르면 조회 중인 기간의 .xlsx 파일이 내려받아진다.
2. 파일에는 요약, 결제 상세, 품목별 3개 시트가 있다.
3. 각 시트 상단에 제목·기간·단위(원), 하단에 자료 출처와 기준일(내려받은 일시)이 표기된다.
4. 인쇄 시 A4 용지 폭에 맞고, 여러 페이지로 나뉘면 표 제목행이 매 페이지 반복된다.
5. 금액 칸은 숫자 형식(천 단위 쉼표)이며, 합계 행은 엑셀 수식(SUM)으로 계산된다.
6. 파일에 전화번호가 포함되지 않고 고객명은 가려져 있다.
7. 관리자만 내려받을 수 있다.

---

## 3. 파일 구성

| 시트 | 열 | 비고 |
| --- | --- | --- |
| 요약 | 날짜(또는 월), 건수, 현금, 카드, 이체, 취소, 순매출 | 합계 행 SUM 수식 |
| 결제 상세 | 결제일시, 접수번호, 고객(가림), 품목, 결제수단, 시기(선/후결제), 금액, 취소일시, 취소 사유 | 취소 건 금액은 별도 열 |
| 품목별 | 품목, 건수, 금액 | 합계 행 SUM 수식 |

- 파일명: `매출_YYYYMM_일별_YYYYMMDD.xlsx`(조회 기간 + 생성일)
- 하단 문구 예: "자료 출처: 수선집 관리 시스템 / 기준일: 2026-11-25 15:30(결제일 기준, 취소는 취소일 기준 차감)"

### 인쇄 설정 (exceljs)

```ts
sheet.pageSetup = {
  paperSize: 9,                 // A4
  orientation: 'landscape',     // 결제 상세 시트(열이 많음), 요약·품목은 portrait
  fitToPage: true, fitToWidth: 1, fitToHeight: 0,
  printTitlesRow: '4:4',        // 표 제목행 반복(제목·기간·단위 3행 아래 헤더)
  margins: { left: 0.5, right: 0.5, top: 0.6, bottom: 0.6, header: 0.3, footer: 0.3 },
};
sheet.headerFooter.oddFooter = '&C&P / &N';   // 쪽 번호
```

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/sales/export?unit=daily&month=2026-11` | 엑셀 파일 생성·응답 | 관리자 |

- 응답 헤더: `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `Content-Disposition: attachment; filename*=UTF-8''...`(한글 파일명)
- 집계는 US-14 `lib/services/sales.ts` 재사용(화면과 파일 값 일치)
- 내려받기 기록을 AuditLog(`SALES_EXPORT`)에 남김
