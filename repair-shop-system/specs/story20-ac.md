## 3. 시나리오 상세 (Given-When-Then)

### AC-20-01 수정 문구로 발송  `정상` `통합`

```gherkin
Scenario: 수정 문구로 발송
  Given 관리자가 완료 안내 문구를 새 문구로 저장했다
  When 접수를 "완료"로 바꾸고 발송 작업자가 실행된다
  Then 발송된 문구(알림 이력)가 새 문구와 같다
```

### AC-20-02 변수 삽입  `정상` `E2E`

```gherkin
Scenario: 변수 삽입
  Given 알림 문구 설정 화면이다
  When 변수 [접수번호] 버튼을 누른다
  Then 커서 위치에 "#{접수번호}"가 삽입된다
```

### AC-20-03 미리보기와 글자 수  `정상` `통합·E2E`

```gherkin
Scenario: 미리보기와 글자 수
  Given 문구에 변수가 포함되어 있다
  When 미리보기를 확인한다
  Then 변수가 예시 값으로 치환된 문구와 글자 수가 표시된다
```

### AC-20-04 정의되지 않은 변수 거부  `입력 검증` `통합`

```gherkin
Scenario: 정의되지 않은 변수 거부
  Given 알림 문구 설정 화면이다
  When 문구에 "#{주소}"를 넣어 저장한다
  Then 저장되지 않고 "#{주소}"가 사용할 수 없는 변수라는 안내가 표시된다
```

### AC-20-05 기본 문구로 되돌리기  `정상` `E2E`

```gherkin
Scenario: 기본 문구로 되돌리기
  Given 문구를 수정해 저장했다
  When [기본 문구로 되돌리기]를 누르고 저장한다
  Then 기본 문구로 복원된다
```

### AC-20-06 매장 정보 반영  `정상` `E2E`

```gherkin
Scenario: 매장 정보 반영
  Given 관리자가 매장명을 "○○수선"으로 저장했다
  When 접수증을 출력하고 문구 미리보기를 확인한다
  Then 두 곳 모두 "○○수선"이 표시된다
```

### AC-20-07 직원 차단  `권한` `통합`

```gherkin
Scenario: 직원 차단
  Given 직원으로 로그인되어 있다
  When 알림 문구 설정 화면이나 API에 접근한다
  Then 접근이 거부된다
```

### AC-20-08 문구 미설정 시 기본 문구 발송  `예외` `통합`

```gherkin
Scenario: 문구 미설정 시 기본 문구 발송
  Given 문구를 한 번도 설정하지 않았다
  When 완료 알림이 발송된다
  Then 기본 문구로 정상 발송된다
```
