## 3. 시나리오 상세 (Given-When-Then)

### AC-06-01 이름 일부로 검색  `정상` `통합`

```gherkin
Scenario: 이름 일부로 검색
  Given 고객 "홍길동", "홍길순", "김철수"가 있다
  When "홍길"로 검색한다
  Then "홍*동", "홍*순"만 표시된다
```

### AC-06-02 전화번호 끝 4자리로 검색  `정상` `통합`

```gherkin
Scenario: 전화번호 끝 4자리로 검색
  Given 고객 "홍길동"(01012345678)이 있다
  When "5678"로 검색한다
  Then "홍*동"이 표시된다
```

### AC-06-03 고객 상세와 수선 이력 표시  `정상` `E2E`

```gherkin
Scenario: 고객 상세와 수선 이력 표시
  Given 고객 "홍길동"에게 접수 3건이 있다
  When 검색 결과에서 "홍*동"을 누른다
  Then 이름, 전체 전화번호, 메모, 총 접수 3건, 최근 방문일이 표시된다
    And 수선 이력 3건이 최근 순으로 접수번호, 품목, 수선 내용, 금액, 상태와 함께 표시된다
```

### AC-06-04 수선 이력에서 접수 상세로 이동  `정상` `E2E`

```gherkin
Scenario: 수선 이력에서 접수 상세로 이동
  Given 고객 상세의 수선 이력이 표시되어 있다
  When 첫 번째 이력 행을 누른다
  Then 해당 접수 상세 화면으로 이동한다
```

### AC-06-05 목록 가림·상세 전체 표시  `보안` `통합`

```gherkin
Scenario: 목록 가림·상세 전체 표시
  Given 고객 "홍길동"이 있다
  When 고객 목록을 조회한다
  Then 전화번호가 "010-****-5678"로 표시된다
  When 고객 상세를 조회한다
  Then 전화번호가 "010-1234-5678"로 표시된다
```

### AC-06-06 고객 상세에서 바로 새 접수  `정상` `E2E`

```gherkin
Scenario: 고객 상세에서 바로 새 접수
  Given 고객 "홍길동" 상세 화면이다
  When [새 접수]를 누른다
  Then 수선 접수 화면이 열리고 고객 칸에 "홍길동"이 선택되어 있다
```

### AC-06-07 접수 화면 검색과 결과 일치  `정상` `통합`

```gherkin
Scenario: 접수 화면 검색과 결과 일치
  Given 같은 검색어 "홍길"을 사용한다
  When 고객 관리 화면과 접수 화면에서 각각 검색한다
  Then 두 화면의 검색 결과 고객이 같다
```
