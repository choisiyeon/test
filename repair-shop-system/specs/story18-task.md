# [US-18] 직원 계정 관리 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E0 공통·설정 |
| 스토리 | 사장님으로서 직원 계정을 만들고 비활성화하고 비밀번호를 초기화하고 싶다. 직원이 바뀌어도 계정을 안전하게 관리하고 작업 기록을 사람별로 남기기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 화면 / 데이터 | S-08 설정(직원 계정 탭) / User, AuditLog |
| 선행 작업 | US-16 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 관리자 전용: 직원 계정 등록, 이름·역할 수정, 비활성화(퇴사)·재활성화, 임시 비밀번호 발급
- 계정은 삭제하지 않고 비활성화(접수·상태 변경·결제 기록의 처리자 정보를 유지하기 위함)
- 임시 비밀번호는 화면에 1회만 표시, 다음 로그인 시 변경 강제(US-16)
- 마지막 관리자 계정은 비활성화·역할 변경 불가(관리자 부재 방지)

---

## 2. 인수 조건

1. 관리자가 아이디·이름·역할을 입력해 등록하면 계정이 생성되고 임시 비밀번호가 1회 표시된다.
2. 이미 있는 아이디로 등록하면 "이미 사용 중인 아이디입니다"가 표시된다.
3. 계정을 비활성화하면 해당 직원은 즉시 로그인할 수 없고, 로그인 중이던 세션도 다음 요청부터 차단된다.
4. 비활성 계정의 과거 작업 기록(접수 등록자 등)은 이름이 그대로 표시된다.
5. [비밀번호 초기화]를 누르면 새 임시 비밀번호가 1회 표시되고, 해당 직원은 다음 로그인 시 비밀번호를 바꿔야 한다.
6. 마지막 남은 관리자 계정은 비활성화하거나 직원으로 바꿀 수 없다.
7. 직원은 계정 관리 화면에 접근할 수 없다.

---

## 3. 데이터 모델 변경

```prisma
model User {
  // ...기존 항목
  sessionVersion Int @default(0)   // 비활성화·초기화 시 증가 → 기존 세션 무효화
}
```

- 세션에 `sessionVersion` 저장, 요청마다(미들웨어 또는 서버 함수) DB 값과 비교해 다르면 로그아웃 처리
- 계정 관련 작업은 AuditLog(`USER_CREATE`, `USER_DEACTIVATE`, `USER_REACTIVATE`, `USER_RESET_PASSWORD`, `USER_ROLE_CHANGE`) 기록

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/users` | 계정 목록(아이디, 이름, 역할, 상태, 마지막 로그인) | 관리자 |
| POST | `/api/users` | 계정 등록 → 임시 비밀번호 반환 | 관리자 |
| PATCH | `/api/users/:id` | 이름·역할·활성 여부 변경 | 관리자 |
| POST | `/api/users/:id/reset-password` | 임시 비밀번호 발급 | 관리자 |

```json
// POST /api/users 응답 201 (임시 비밀번호는 이 응답에만 포함, 저장은 해시만)
{ "id": "ck...", "loginId": "staff02", "tempPassword": "k7Rm-2pQx" }

// PATCH 응답 409 (마지막 관리자)
{ "error": "LAST_ADMIN" }
```

### 규칙

- 아이디: 영문 소문자·숫자 4~20자(제안값), 등록 후 변경 불가
- 임시 비밀번호: 암호학적 난수로 생성, US-16 비밀번호 규칙 충족
- 관리자는 자기 자신을 비활성화할 수 없음

```
직원 계정                                         [+ 계정 등록]
│ 아이디   │ 이름   │ 역할  │ 상태  │ 마지막 로그인 │                        │
│ owner    │ 사장님 │ 관리자 │ 사용  │ 11-25 09:02  │ [수정]                  │
│ staff01  │ 직원A  │ 직원  │ 사용  │ 11-25 10:15  │ [수정][비밀번호 초기화][비활성화] │
│ staff00  │ 직원B  │ 직원  │ 중지  │ 09-30 18:20  │ [재활성화]               │
```

- 임시 비밀번호 표시 창: "이 창을 닫으면 다시 볼 수 없습니다" + [복사] 버튼
