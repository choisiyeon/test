## 2. 테스트 전제·데이터

- 공통: 관리자 "owner", 직원 "staff01" 계정, 시험 시각은 한국 시간(KST) 기준으로 고정
- 정상 사진 JPEG 2장, PNG 1장
- 위치정보(GPS)가 포함된 JPEG 1장
- 동영상(.mov) 1개, 제안 기준(10MB) 초과 사진 1장

## 3. 시나리오 상세 (Given-When-Then)

### AC-03-01 접수 시 사진 미리보기와 함께 저장  `정상` `E2E`

```gherkin
Scenario: 접수 시 사진 미리보기와 함께 저장
  Given 직원으로 로그인되어 수선 접수 화면을 열었다
  When [사진 추가]로 JPEG 2장을 선택한다
  Then 미리보기 2개가 표시된다
  When 접수를 저장한다
  Then 접수 상세에 사진 썸네일 2개가 표시된다
```

### AC-03-02 접수 상세에서 사진 추가  `정상` `E2E`

```gherkin
Scenario: 접수 상세에서 사진 추가
  Given 사진 1장이 첨부된 접수가 있다
  When 접수 상세에서 [사진 추가]로 1장을 더 올린다
  Then 썸네일이 2개로 늘어난다
```

### AC-03-03 허용되지 않은 형식 거부  `입력 검증` `통합·E2E`

```gherkin
Scenario: 허용되지 않은 형식 거부
  Given 직원이 접수 상세 화면을 열었다
  When 동영상 파일(.mov)을 업로드한다
  Then "허용되지 않는 형식입니다" 안내가 표시된다
    And 사진이 저장되지 않는다
```

### AC-03-04 용량 초과·최대 장수 초과 거부  `입력 검증` `통합`

```gherkin
Scenario: 용량 초과·최대 장수 초과 거부
  Given 이미 최대 장수(제안값 5장)까지 사진이 첨부된 접수가 있다
  When 사진 1장을 더 올린다
  Then 업로드가 거부되고 최대 장수 안내가 표시된다
  Given 사진이 없는 접수가 있다
  When 기준 용량을 초과한 사진과 정상 사진을 함께 올린다
  Then 정상 사진만 저장되고 초과 사진은 거부 사유와 함께 표시된다
```

### AC-03-05 사진 크게 보기  `정상` `E2E`

```gherkin
Scenario: 사진 크게 보기
  Given 사진 2장이 첨부된 접수 상세 화면이다
  When 첫 번째 썸네일을 누른다
  Then 사진이 크게 표시되고 좌우로 넘겨 볼 수 있다
```

### AC-03-06 사진 삭제 권한  `권한` `E2E·통합`

```gherkin
Scenario: 사진 삭제 권한
  Given 사진이 첨부된 접수가 있다
  When 직원이 접수 상세를 연다
  Then 사진 [삭제] 버튼이 보이지 않고, 삭제 API 요청 시 403 응답이 반환된다
  When 관리자가 [삭제]를 누르고 확인한다
  Then 해당 사진이 목록에서 사라진다
```

### AC-03-07 업로드 실패 시 접수 정보 유지  `예외` `통합·E2E`

```gherkin
Scenario: 업로드 실패 시 접수 정보 유지
  Given 사진 저장소에 연결할 수 없는 상태다
  When 직원이 사진을 선택하고 접수를 저장한다
  Then 접수는 정상 저장된다
    And 접수 상세에 "사진 업로드 실패, 다시 첨부하세요" 안내가 표시된다
```

### AC-03-08 촬영 위치정보 제거  `보안` `단위`

```gherkin
Scenario: 촬영 위치정보 제거
  Given 위치정보(GPS)가 포함된 사진이 있다
  When 사진을 업로드한다
  Then 저장된 사진 파일에 촬영 위치·기기 정보(EXIF)가 남아 있지 않다
```

### AC-03-09 로그인 사용자만 사진 열람  `보안` `통합`

```gherkin
Scenario: 로그인 사용자만 사진 열람
  Given 사진 주소(서명 URL)가 발급되었다
  When 유효시간이 지난 뒤 같은 주소로 접근한다
  Then 사진이 열리지 않는다
```
