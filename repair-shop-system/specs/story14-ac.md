## 2. 테스트 전제·데이터

- 공통: 관리자 "owner", 직원 "staff01" 계정, 시험 시각은 한국 시간(KST) 기준으로 고정
- 시험 결제: 11-01 현금 10,000원, 11-01 카드 20,000원, 11-24 이체 8,000원(11-25 취소), 11-25 23:59 카드 5,000원, 11-26 00:00 현금 3,000원(모두 KST)
- ※ 금액은 시험용 가상 데이터

## 3. 시나리오 상세 (Given-When-Then)

### AC-14-01 기간별 건수·금액  `정상` `통합·E2E`

```gherkin
Scenario: 기간별 건수·금액
  Given 관리자로 로그인되어 있다
  When 일별, 2026년 11월을 선택한다
  Then 11-01 행에 건수 2, 순매출 30000이 표시된다
```

### AC-14-02 결제수단별·품목별 합계  `정상` `통합`

```gherkin
Scenario: 결제수단별·품목별 합계
  Given 시험 결제가 있다
  When 11월 매출을 조회한다
  Then 현금·카드·이체별 합계와 품목별 합계가 함께 표시된다
```

### AC-14-03 취소 차감  `정상` `통합`

```gherkin
Scenario: 취소 차감
  Given 11-24 이체 8000원이 11-25에 취소되었다
  When 11월 일별 매출을 조회한다
  Then 11-24 총매출에 8000이, 11-25 취소액에 8000이 표시되고 순매출에 반영된다
```

### AC-14-04 합계 일치  `정상` `단위`

```gherkin
Scenario: 합계 일치
  Given 11월 매출을 조회했다
  When 결제수단별 합계를 모두 더한다
  Then 표 하단 전체 합계와 같다
```

### AC-14-05 직원 접근 차단  `권한` `E2E·통합`

```gherkin
Scenario: 직원 접근 차단
  Given 직원으로 로그인되어 있다
  When 메뉴를 확인한다
  Then 매출 메뉴가 보이지 않는다
  When 매출 API를 요청한다
  Then 403 응답이 반환된다
```

### AC-14-06 결제 없는 날짜 0원 표시  `정상` `통합`

```gherkin
Scenario: 결제 없는 날짜 0원 표시
  Given 11-02에 결제가 없다
  When 11월 일별 매출을 조회한다
  Then 11-02 행이 건수 0, 금액 0으로 표시된다
```

### AC-14-07 한국 시간 날짜 경계  `정상` `단위`

```gherkin
Scenario: 한국 시간 날짜 경계
  Given 11-25 23:59와 11-26 00:00(KST) 결제가 있다
  When 일별 매출을 조회한다
  Then 앞의 건은 11-25, 뒤의 건은 11-26에 집계된다
```

### AC-14-08 월별 조회  `정상` `통합`

```gherkin
Scenario: 월별 조회
  Given 관리자로 로그인되어 있다
  When 월별, 2026년을 선택한다
  Then 1월~12월 12개 행이 표시되고 결제 없는 월은 0원이다
```

### AC-14-09 단위·기준 표기  `정상` `E2E`

```gherkin
Scenario: 단위·기준 표기
  Given 매출 화면을 열었다
  When 표를 확인한다
  Then 표 상단에 "(단위: 원)", 하단에 집계 기준과 조회 일시가 표시된다
```
