## 3. 시나리오 상세 (Given-When-Then)

### AC-17-01 지표 카드 표시  `정상` `통합·E2E`

```gherkin
Scenario: 지표 카드 표시
  Given 직원으로 로그인되어 있다
  When 대시보드를 연다
  Then 접수, 작업중, 완료(미출고), 기한 경과, 미수령, 오늘 알림 실패 건수 카드가 표시된다
```

### AC-17-02 카드 숫자와 목록 건수 일치  `정상` `E2E`

```gherkin
Scenario: 카드 숫자와 목록 건수 일치
  Given 대시보드가 열려 있다
  When 각 카드를 누른다
  Then 해당 조건이 적용된 목록 화면으로 이동한다
    And 목록 총건수가 카드 숫자와 같다
```

### AC-17-03 오늘 완료 예정 목록  `정상` `통합`

```gherkin
Scenario: 오늘 완료 예정 목록
  Given 오늘 완료 예정 미완료 건 2건, 오늘 예정이지만 완료된 건 1건이 있다
  When 대시보드를 연다
  Then 오늘 완료 예정 목록에 미완료 2건만 표시된다
```

### AC-17-04 관리자 전용 매출 카드  `권한` `통합·E2E`

```gherkin
Scenario: 관리자 전용 매출 카드
  Given 오늘 결제가 있다
  When 직원이 대시보드를 연다
  Then 오늘 순매출 카드가 표시되지 않고 API 응답 값이 비어 있다
  When 관리자가 대시보드를 연다
  Then 오늘 순매출 카드가 표시되고 매출 화면의 오늘 순매출과 같다
```

### AC-17-05 새 접수 바로가기  `정상` `E2E`

```gherkin
Scenario: 새 접수 바로가기
  Given 대시보드다
  When [새 접수]를 누른다
  Then 수선 접수 화면으로 이동한다
```

### AC-17-06 자동 새로고침  `정상` `E2E`

```gherkin
Scenario: 자동 새로고침
  Given 대시보드가 열려 있다
  When 다른 직원이 새 접수를 등록하고 새로고침 주기가 지난다
  Then 접수 카드 숫자가 1 늘어난다
```

### AC-17-07 강조 표시  `정상` `E2E`

```gherkin
Scenario: 강조 표시
  Given 기한 경과 건이 1건 이상 있다
  When 대시보드를 연다
  Then 기한 경과 카드가 색과 ⚠ 기호로 강조된다
```

### AC-17-08 미구현 지표 숨김  `예외` `통합`

```gherkin
Scenario: 미구현 지표 숨김
  Given 아직 출시되지 않은 기능의 지표 값이 비어 있다
  When 대시보드를 연다
  Then 해당 카드는 표시되지 않고 화면 오류도 발생하지 않는다
```
