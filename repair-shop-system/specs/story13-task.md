# [US-13] 결제 취소·환불 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E4 매출·정산 |
| 스토리 | 사장님으로서 잘못 기록된 결제를 취소하거나 고객에게 환불한 내역을 기록하고 싶다. 매출 기록을 실제 금액과 일치시키기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 기능 | 사용자 및 권한표 '결제 취소·환불(관리자 전용)' |
| 관련 화면 / 데이터 | 접수 상세 / D-03 결제, AuditLog |
| 선행 작업 | US-12, US-07(AuditLog) |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- 결제 기록은 삭제하지 않고 '취소 표시'(canceledAt)로 처리 → 원래 결제와 취소 이력이 모두 남음
- 전액 취소만 지원(부분 환불은 2차 검토)
- 관리자만 가능, 사유 필수, AuditLog 기록
- 취소된 결제는 매출 집계(US-14)에서 취소일 기준으로 차감
- 카드 단말기 미연동 전제: 시스템은 '기록'만 하며 실제 카드 취소는 단말기에서 별도 처리

---

## 2. 인수 조건

1. 관리자가 접수 상세의 결제 내역에서 [결제 취소]를 누르고 사유를 입력하면 결제가 '취소'로 표시된다.
2. 취소된 결제는 결제 내역에 취소선과 취소 일시·사유·처리자가 함께 표시된다.
3. 직원 화면에는 [결제 취소] 버튼이 없고, API로 요청해도 거부된다.
4. 결제를 취소하면 해당 건은 '미결제' 상태가 되어 다시 결제를 기록할 수 있다.
5. 취소 금액은 취소일 매출에서 차감되어 집계된다.
6. 이미 취소된 결제는 다시 취소할 수 없다.

---

## 3. 데이터 모델 변경

- US-12 Payment의 `canceledAt`, `canceledById`, `cancelReason` 사용
- 재결제 허용을 위해 `orderId @unique` 제약을 '취소되지 않은 결제 1건'으로 변경

```sql
-- Prisma 마이그레이션에 SQL로 추가(부분 고유 인덱스)
DROP INDEX "Payment_orderId_key";
CREATE UNIQUE INDEX "Payment_orderId_active_key" ON "Payment"("orderId") WHERE "canceledAt" IS NULL;
```

- Order의 `payment Payment?` 관계는 `payments Payment[]`로 변경, '현재 결제' = 취소되지 않은 1건
- US-12 코드의 결제 조회 부분을 공통 함수 `getActivePayment(orderId)`로 교체

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| POST | `/api/payments/:id/cancel` | 결제 취소 | 관리자 |

```json
// 요청
{ "reason": "결제수단 오기록(현금→카드)" }
// 응답 200
{ "id": "ck...", "canceledAt": "2026-11-25T15:10:00+09:00" }
// 응답 403 (직원) / 409 { "error": "ALREADY_CANCELED" }
```

### 처리 순서 (하나의 트랜잭션)

1. 관리자·사유 확인
2. `UPDATE payment SET canceledAt=now(), ... WHERE id=? AND canceledAt IS NULL` → 영향 행 0이면 409
3. AuditLog(`PAYMENT_CANCEL`, 대상 결제 id, 사유) 저장
4. 출고된 건이면 Order.releasedUnpaid는 변경하지 않음(출고 상태 유지, 상세에 '결제 취소됨' 표시)

## 5. 화면

```
결제 내역
│ 11-25 14:30 │ ~~현금 8,000원~~ │ 직원A │ 취소됨(11-25 15:10, 사장님, 사유: 결제수단 오기록) │
│ 11-25 15:12 │ 카드 8,000원     │ 사장님 │ [결제 취소]                                  │
```

- 취소 확인 창: "결제 기록만 취소됩니다. 카드 결제는 단말기에서 별도로 취소하세요." + 사유 입력
