## 3. 시나리오 상세 (Given-When-Then)

### AC-09-01 완료 시 자동 발송 성공  `정상` `통합`

```gherkin
Scenario: 완료 시 자동 발송 성공
  Given 발송 어댑터가 '성공'으로 설정되어 있다
    And 접수 B의 상태가 "작업중"이다
  When 직원이 접수 B를 "완료"로 변경하고 발송 작업자가 실행된다
  Then 고객 번호로 수령 안내 1건이 발송된다
    And 알림 이력에 유형 "자동", 결과 "성공"으로 기록된다
```

### AC-09-02 발송 문구 포함 항목  `정상` `단위`

```gherkin
Scenario: 발송 문구 포함 항목
  Given 매장명 "○○수선", 접수번호 "20261125-007", 품목 "바지 기장 줄임"이다
  When 완료 안내 문구를 만든다
  Then 문구에 매장명, 접수번호, 품목, 수령 안내가 포함된다
```

### AC-09-03 발송 실패 기록과 재발송  `예외` `통합·E2E`

```gherkin
Scenario: 발송 실패 기록과 재발송
  Given 발송 어댑터가 '실패'로 설정되어 있다
  When 접수가 완료되고 발송 작업자가 실행된다
  Then 알림 이력에 결과 "실패"와 사유가 기록된다
    And 접수 상세에 "알림 발송 실패" 표시와 [다시 보내기] 버튼이 나타난다
  When 발송 어댑터를 '성공'으로 바꾸고 [다시 보내기]를 누른다
  Then 유형 "수동", 결과 "성공" 이력이 추가된다
```

### AC-09-04 자동 발송 1회 원칙  `예외` `통합`

```gherkin
Scenario: 자동 발송 1회 원칙
  Given 접수 B가 완료되어 자동 발송이 성공했다
  When 관리자가 "작업중"으로 되돌린 뒤 다시 "완료"로 바꾼다
  Then 자동 발송 이력은 1건만 존재한다
```

### AC-09-05 발송 업체 미설정 시 업무 정상 처리  `예외` `통합`

```gherkin
Scenario: 발송 업체 미설정 시 업무 정상 처리
  Given 발송 어댑터가 '미설정'이다
  When 접수를 "완료"로 변경한다
  Then 상태 변경은 정상 처리된다
    And 알림 이력에 결과 "미설정"으로 기록된다
```

### AC-09-06 대상 없음 처리  `예외` `통합`

```gherkin
Scenario: 대상 없음 처리
  Given 완료 처리 전에 고객 정보가 삭제(익명화)되었다
  When 발송 작업자가 이벤트를 처리한다
  Then 발송하지 않고 알림 이력에 "대상 없음"으로 기록된다
```

### AC-09-07 작업자 재시작 시 누락 없음  `예외` `통합`

```gherkin
Scenario: 작업자 재시작 시 누락 없음
  Given 미처리 완료 이벤트 3건이 있다
  When 발송 작업자를 중지했다가 다시 시작한다
  Then 3건이 모두 1번씩 처리된다
```

### AC-09-08 알림 이력 번호 가림  `보안` `통합`

```gherkin

  Given 알림이 발송되었다
  When 알림 이력을 조회한다
  Then 수신 번호가 "010-****-5678"로만 저장되어 있다
```
