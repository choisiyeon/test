## 3. 시나리오 상세 (Given-When-Then)

### AC-01-01 필수 항목 입력 후 접수 저장  `정상` `E2E·통합`

```gherkin
Scenario: 필수 항목 입력 후 접수 저장
  Given 직원 계정 "staff01"로 로그인되어 있다
    And 수선 접수 화면을 열었다
  When 고객 "홍길동", 품목 "바지 기장 줄임", 수선 내용 "기장 3cm 줄임", 금액 8000, 완료 예정일 "2026-11-28"을 입력하고 [접수 저장]을 누른다
  Then 접수 상세 화면으로 이동한다
    And 접수번호가 "20261125-" + 3자리 일련번호 형식으로 표시된다
    And 상태가 "접수"로 표시된다
    And 접수 기록의 등록자가 "staff01"로 저장된다
```

### AC-01-02 필수 항목 누락 시 저장 거부  `입력 검증` `E2E·통합`

```gherkin
Scenario: 필수 항목 누락 시 저장 거부
  Given 직원으로 로그인되어 수선 접수 화면을 열었다
  When 수선 내용을 비워 두고 나머지 필수 항목을 입력한 뒤 [접수 저장]을 누른다
  Then 수선 내용 입력 칸에 "수선 내용을 입력하세요" 안내가 표시된다
    And 접수 건수가 늘어나지 않는다
    And 접수 등록 API는 400 응답과 누락 항목 이름을 반환한다
```

### AC-01-03 완료 예정일 과거 날짜 거부  `입력 검증` `통합`

```gherkin
Scenario: 완료 예정일 과거 날짜 거부
  Given 직원으로 로그인되어 있다
  When 완료 예정일을 "2026-11-24"(어제)로 입력해 접수를 저장한다
  Then 저장되지 않고 "완료 예정일은 오늘 이후 날짜여야 합니다" 안내가 표시된다
```

### AC-01-04 미등록 고객을 접수 화면에서 신규 등록  `정상` `E2E`

```gherkin
Scenario: 미등록 고객을 접수 화면에서 신규 등록
  Given 직원으로 로그인되어 수선 접수 화면을 열었다
    And 고객 검색 결과에 "김영희"가 없다
  When [+신규]를 눌러 이름 "김영희", 전화번호 "010-2222-3333"을 저장한다
  Then 신규 고객이 등록된다
    And 접수 화면 고객 칸에 "김영희"가 자동 선택된다
```

### AC-01-05 기본 단가 자동 입력  `정상` `E2E`

```gherkin
Scenario: 기본 단가 자동 입력
  Given 품목 "지퍼 교체"에 기본 단가가 지정되어 있다
  When 접수 화면에서 품목 "지퍼 교체"를 선택한다
  Then 금액 칸에 기본 단가가 입력된다
    And 직원은 금액을 수정할 수 있다
```

### AC-01-06 접수증 출력  `정상` `E2E`

```gherkin
Scenario: 접수증 출력
  Given 접수 "20261125-001"이 저장되었다
  When 접수 상세에서 [접수증 출력]을 누른다
  Then 인쇄 화면에 매장명, 접수번호, 접수일, 고객명, 전화번호 뒤 4자리, 품목, 수선 내용, 금액, 완료 예정일이 표시된다
    And 브라우저 인쇄 기능이 호출된다
```

### AC-01-07 프린터 오류와 무관하게 접수 유지  `예외` `E2E·통합`

```gherkin
Scenario: 프린터 오류와 무관하게 접수 유지
  Given 접수를 저장한 뒤 인쇄 화면을 열었다
  When 인쇄를 취소하거나 프린터 오류로 인쇄되지 않는다
  Then 접수 정보는 그대로 저장되어 있다
    And 접수 상세에서 다시 출력할 수 있다
```

### AC-01-08 동시 접수 시 접수번호 중복 없음  `예외` `단위·통합`

```gherkin
Scenario: 동시 접수 시 접수번호 중복 없음
  Given 같은 날짜에 접수 요청 10건이 동시에 들어온다
  When 10건이 모두 저장된다
  Then 10건의 접수번호가 모두 다르다
    And 일련번호가 001부터 빠짐없이 부여된다
```

### AC-01-09 로그인하지 않은 접근 차단  `권한` `통합`

```gherkin
Scenario: 로그인하지 않은 접근 차단
  Given 로그인하지 않은 상태다
  When 수선 접수 화면 또는 접수 등록 API에 접근한다
  Then 화면은 로그인 화면으로 이동하고, API는 401 응답을 반환한다
```

### AC-01-10 목록 화면 전화번호 가림  `보안` `통합`

```gherkin
Scenario: 목록 화면 전화번호 가림
  Given 고객 "홍길동"(01012345678)이 등록되어 있다
  When 접수 화면에서 고객을 검색한다
  Then 검색 결과에 전화번호가 "010-****-5678"로 표시된다
    And API 응답에 전화번호 원문이 포함되지 않는다
```
