# [US-17] 대시보드 — 개발 Task 설계서

| 항목 | 내용 |
| --- | --- |
| 에픽 | E0 공통·설정 |
| 스토리 | 사장님과 직원으로서 로그인하자마자 오늘 처리할 일을 한 화면에서 보고 싶다. 마감이 다가온 작업과 미처리 건을 놓치지 않기 위해서다. |
| 우선순위 / 릴리스 | 필수 / 1차 |
| 관련 화면 / 데이터 | S-02 대시보드 / D-02 접수, D-03 결제, D-04 알림 이력 |
| 선행 작업 | US-02(최초 대시보드), US-04, US-08, US-09, US-12 |
| 작성일 | 2026-11-25 |

---

## 1. 요약

- US-02에서 만든 최초 대시보드를 최종 형태로 정리하고, 다른 스토리에서 추가된 지표를 한곳에 통합
- 카드형 지표(건수) + 오늘 완료 예정 목록 + 빠른 이동 버튼
- 관리자에게만 '오늘 매출' 카드 표시
- 모든 카드는 누르면 해당 조건이 적용된 목록 화면으로 이동

---

## 2. 인수 조건

1. 대시보드에 접수·작업중·완료(미출고)·기한 경과·미수령·오늘 알림 실패 건수가 카드로 표시된다.
2. 각 카드를 누르면 해당 조건으로 검색된 목록 화면으로 이동한다.
3. '오늘 완료 예정' 목록에 완료 예정일이 오늘인 미완료 건이 표시된다.
4. 관리자에게만 '오늘 순매출' 카드가 표시되며 매출 화면(US-14) 값과 일치한다.
5. [새 접수] 버튼으로 바로 접수 화면으로 이동할 수 있다.
6. 대시보드 숫자는 화면을 열 때와 일정 주기마다 자동으로 새로고침된다.

---

## 3. 지표 정의

| 카드 | 정의 | 이동 화면 |
| --- | --- | --- |
| 접수 | 상태 = 접수 | 접수 목록 `?status=RECEIVED` |
| 작업중 | 상태 = 작업중 | 접수 목록 `?status=IN_PROGRESS` |
| 완료(미출고) | 상태 = 완료 | 접수 목록 `?status=DONE` |
| 기한 경과 | US-04 overdue 정의 | 접수 목록 `?overdue=true` |
| 미수령 | US-08 미수령 정의 | 미수령 탭 |
| 오늘 알림 실패 | 오늘 NotificationLog 결과 FAILED(재발송 성공 건 제외) | 알림 이력 `?result=FAILED&from=오늘` |
| 오늘 순매출(관리자) | US-14 순매출 정의, 오늘 하루 | 매출 화면 |

- 지표 계산 로직은 각 스토리 서비스 함수를 재사용(대시보드 전용 계산식 만들지 않음 → 목록 결과와 불일치 방지)

---

## 4. API 설계

| 메서드 | 경로 | 설명 | 권한 |
| --- | --- | --- | --- |
| GET | `/api/dashboard/summary` | 카드 지표 일괄(US-02 API 확장) | 관리자·직원(매출은 관리자만 포함) |
| GET | `/api/dashboard/due-today` | 오늘 완료 예정 목록 | 관리자·직원 |

```json
{ "received": 0, "inProgress": 0, "doneNotReleased": 0, "overdue": 0,
  "unclaimed": 0, "notifyFailedToday": 0, "todayNetSales": null,   // 직원이면 null
  "generatedAt": "2026-11-25T15:40:00+09:00" }
```

- 아직 구현되지 않은 스토리의 지표는 `null` 반환 → 화면에서 카드 숨김(단계별 릴리스 대응)

---

## 5. 화면 (S-02 대시보드)

```
오늘 2026-11-25(수)                                   [ + 새 접수 ]
┌ 접수 ┐ ┌ 작업중 ┐ ┌ 완료(미출고) ┐ ┌ 기한 경과 ⚠ ┐ ┌ 미수령 ┐ ┌ 알림 실패 ┐ ┌ 오늘 순매출(원) ┐
│  n  │ │   n   │ │     n      │ │     n      │ │   n   │ │    n     │ │      n         │
└─────┘ └───────┘ └────────────┘ └────────────┘ └───────┘ └──────────┘ └────────────────┘
오늘 완료 예정 (n건)
│ 접수번호 │ 고객 │ 품목 │ 상태 │ [작업 완료] │
                                       마지막 갱신 15:40
```

- 기한 경과·알림 실패가 1건 이상이면 카드 강조(색 + ⚠ 기호)
- 자동 새로고침 주기(예: 1분)는 제안값
